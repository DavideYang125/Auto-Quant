# Auto-Quant 策略详解与优化记录

## 核心指标说明

### Sharpe Ratio（夏普比率）

**公式：** `Sharpe = (策略收益 - 无风险利率) / 收益标准差`

**含义：** 每承担一单位风险能获得多少超额收益

**评判标准：**
| Sharpe值 | 评级 | 说明 |
|----------|------|------|
| > 2.0 | 优秀 | 可以考虑实盘 |
| > 1.0 | 良好 | 接近可用，继续优化 |
| > 0.5 | 一般 | 有一定正收益，但风险大 |
| > 0.0 | 勉强 | 比什么都不做强一点 |
| < 0.0 | 失败 | 不如买指数持有 |

**我们的结果：** 最高0.17，远低于实盘标准（需>1.0）

### Profit Factor（盈亏比）

**公式：** `Profit Factor = 所有盈利交易总额 / 所有亏损交易总额`

**含义：** 每亏损1元能盈利多少

**评判标准：**
| PF值 | 评级 | 说明 |
|-------|------|------|
| > 2.0 | 优秀 | 每1元亏损换2元盈利 |
| > 1.5 | 良好 | 盈亏结构健康 |
| > 1.0 | 及格 | 总体盈利 |
| = 1.0 | 平衡 | 不赚不赔 |

**我们的结果：** MacdMomentum的1.37最好，但仍不够优秀

### Max Drawdown（最大回撤）

**含义：** 从历史最高点到最低点的最大跌幅

**示例：**
```
账户从100涨到150，然后跌到120，再涨到200
最大回撤 = (150-120)/150 = 20%
```

## 策略详解

### 1. TrendFollow（趋势跟踪）

**核心思想：** 趋势一旦形成会持续，跟随趋势获利

**交易逻辑：**
```
入场条件（同时满足）：
1. EMA9 > EMA21（短期均线上穿长期均线）
2. Momentum > 1%（过去10小时涨幅超过1%）

出场条件：
EMA9 < EMA21（趋势反转）
```

**参数说明：**
| 参数 | 当前值 | 含义 | 调整影响 |
|------|--------|------|----------|
| EMA快线周期 | 9 | 反应速度 | 太小=噪音多，太大=滞后 |
| EMA慢线周期 | 21 | 趋势确认 | 太小=假信号，太大=错过机会 |
| Momentum阈值 | 1% | 动量强度 | 太低=频繁交易，太高=错过机会 |

**优化历史：**
- Round 6: 尝试添加ADX>20过滤 → **失败**，Sharpe从0.17降到0.15
- 原因：ADX滞后，在交叉时才确认趋势，已经晚了

**最终表现：**
```
Sharpe: 0.17（三个策略中最好）
BTC: 0.27, ETH: 0.08
交易数: 6537
问题：回撤-31%较大，盈利被亏损抵消
```

### 2. MacdMomentum（MACD动量）

**核心思想：** MACD金叉表示动量转换，结合趋势过滤提高胜率

**交易逻辑：**
```
入场条件（同时满足）：
1. MACD线上穿MACD信号线（金叉）
2. MACD > 0（在零轴上方，多头区域）
3. ROC > 1.5%（过去10小时变化率）
4. Close > SMA50（中期上升趋势）
5. Close > 前一根Close（价格上涨）

出场条件：
（未设置，依赖后续数据或止损）
```

**参数说明：**
| 参数 | 当前值 | 含义 | 调整影响 |
|------|--------|------|----------|
| MACD快线 | 12 | 快速移动平均 | 标准参数 |
| MACD慢线 | 26 | 慢速移动平均 | 标准参数 |
| MACD信号线 | 9 | MACD的平滑 | 标准参数 |
| ROC阈值 | 1.5% | 动量确认 | Round 3:2%→Round 4:1.5% |
| SMA50 | 50 | 趋势过滤 | Round 4新增 |

**优化历史：**
- Round 3: 创建，Sharpe 0.10，比VolatilityBreak的0.02好5倍
- Round 4: 添加SMA50趋势过滤，ROC从2%降到1.5% → **成功**，Sharpe升到0.12
- Round 5: 再加SMA200双重过滤 → **失败**，Sharpe降到0.10
- 回退原因：过度过滤，错过太多机会

**最终表现：**
```
Sharpe: 0.12
BTC: 0.22（优秀）, ETH: -0.00（接近平衡）
交易数: 109（最少，选择性高）
最大回撤: -8.1%（最好，风控优秀）
Profit Factor: 1.37（最好）
```

### 3. MeanRevRSI（均值回归）

**核心思想：** 价格过度偏离后会回归均值，在超卖区域买入

**交易逻辑：**
```
入场条件（同时满足）：
1. RSI < 40（超卖区域）
2. Close < BB_middle（价格低于布林带中轨）

出场条件：
（未在代码中明确设置）
```

**参数说明：**
| 参数 | 当前值 | 含义 | 调整影响 |
|------|--------|------|----------|
| RSI周期 | 14 | RSI计算周期 | 标准参数 |
| RSI入场阈值 | 40 | 超卖判断 | 原策略<20，我们放宽到<40 |
| BB周期 | 20 | 布林带周期 | 标准参数 |
| BB标准差 | 2 | 布林带宽度 | 标准参数 |

**优化历史：**
- 未进行针对性优化，保持初始配置
- 交易频率过高（8994笔），换手成本会吃掉利润

**最终表现：**
```
Sharpe: 0.12
BTC: 0.18, ETH: 0.07
交易数: 8994（最多）
问题：频繁交易，实际收益会被手续费侵蚀
```

### 4. VolatilityBreak（波动率突破）- 已淘汰

**为什么失败？**
- 初始Sharpe仅0.03，BTC亏损-0.16
- Round 2改进后反而更差（0.03→0.02）
- 信号后平均收益仅0.03%，几乎为零
- 胜率47.5%，低于随机（50%）

**核心问题：**
加密货币的波动率突破往往是"假突破"，
价格突破后很快回落，无法持续获利。

## 为什么是6轮测试？

### 不是预先设定的6轮！

每一轮都是根据上一轮结果决定的：

```
Round 1: 创建3个初始策略
├─ MeanRevRSI: Sharpe 0.12 ✓
├─ TrendFollow: Sharpe 0.17 ✓
└─ VolatilityBreak: Sharpe 0.03 ✗ → 需要改进

Round 2: 改进VolatilityBreak
├─ 添加SMA200趋势过滤
├─ 降低波动率阈值 0.02→0.01
└─ 结果: Sharpe 0.02 ✗ 更差了 → 放弃

Round 3: 创建MacdMomentum替代VolatilityBreak
├─ MACD金叉 + ROC > 2%
└─ 结果: Sharpe 0.10 ✓ 有效！

Round 4: 优化MacdMomentum
├─ 添加SMA50趋势过滤
├─ 降低ROC阈值 2%→1.5%
└─ 结果: Sharpe 0.12 ✓ 改善！

Round 5: 尝试进一步改进MacdMomentum
├─ 再加SMA200双重过滤
└─ 结果: Sharpe 0.10 ✗ 回退

Round 6: 尝试改进表现最好的TrendFollow
├─ 添加ADX趋势强度过滤
└─ 结果: Sharpe 0.15 ✗ 回退

结论: 当前配置已是局部最优
└─ 需要更多数据或其他方向才能继续
```

### 何时停止测试？

**停止信号：**
1. 连续2轮改进失败（如Round 5、6）
2. Sharpe无法再提升（进入平台期）
3. 需要新数据或其他思路

**继续信号：**
1. 发现新的改进方向
2. 获得更多历史数据（目前只有BTC+ETH）
3. 测试新的策略范式

### 参数调整思路

**通用原则：**
1. 一次只调一个参数
2. 记录每次变化和结果
3. 效果不好立即回退
4. 避免过度优化（过拟合）

**调整方向：**
- 如果交易太少 → 放宽条件（降低阈值）
- 如果胜率太低 → 增加过滤（添加条件）
- 如果回撤太大 → 添加止损
- 如果收益太低 → 检查是否过度过滤
